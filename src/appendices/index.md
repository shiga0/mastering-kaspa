# Appendices（付録）

本文を読む途中で必要になる準備手順・用語・数式・参照情報をまとめています。最初から通読する必要はありません。実習の準備や、説明の根拠を確かめたいときに使ってください。

## 目的から探す

| 確認したいこと | 参照先 |
|---|---|
| Rust・Docker・Devnetなどの実習環境を準備する | [付録A：環境構築](appendix-a.md) |
| 用語の意味や関連する章を調べる | [付録B：用語集](appendix-b.md) |
| 集合・確率・暗号技術などの数学的な前提を補う | [付録C：数学・確率・暗号技術](appendix-c.md) |
| RPC・CLIの入口や使い方を調べる | [付録D：RPC・CLIリファレンス](appendix-d.md) |
| 基準版のパラメータ・単位・適用条件を確認する | [付録E：パラメータ一覧](appendix-e.md) |
| 論文・KIPから実装や検証への対応をたどる | [付録F：論文・KIP・実装対応表](appendix-f.md) |
| 実験の入力・期待値・実測記録と確認範囲を調べる | [付録G：実験結果・テストベクトル](appendix-g.md) |
| 参考文献、版の扱い、レビュー判定、変更履歴を確認する | [付録H：参考文献・変更履歴](appendix-h.md) |

## 利用するときの前提

実装・SDK・ネットワークの対象は[本書の対象バージョン](../baseline.md)を確認してください。表の定数やAPI名は、現在のすべてのネットワーク・リリースに共通する値とは限りません。

実験の計画・教材の例・実測結果は区別して記載しています。個々の検証で確認した範囲と、未検証の制限は[技術レビューの進捗](../review-status.md)および各実験記録を参照してください。
